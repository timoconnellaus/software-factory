software-factory: app map

One object runs through the whole app: the work item. Everything else is a view of work items, a decision about one, or setup for the factory that builds them. Org, then project, then work item, then run. A project is a body of work that runs on a workflow. The workflow sets its stages and, for code, which repositories it works in.

1. Org pickerWhich org. All orgs is a merged inbox and nothing else.
