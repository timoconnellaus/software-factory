Scope
•The GitHub App webhook takes issues events for connected repositoriesrepo
•Only issues with the factory label come inQ1
•Authors must be org members or collaborators; anything else is ignored and loggedQ2
•New items land in the Backlog of the project that owns the repositoryQ3
